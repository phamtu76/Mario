MARIO 2D ASSET PACK
====================

Các file được tách từ ảnh asset tổng hợp:

characters_mario.png
- Khu vực Mario: idle, run, jump, hurt, dead.
- Dùng làm tài liệu tham khảo/sprite sheet.

enemies.png
- Goomba và Koopa.
- Dùng làm tài liệu tham khảo/sprite sheet.

items.png
- Coin và Mushroom.

tiles.png
- Ground, Brick, Question Block, Pipe, Platform.

background.png
- Cloud và background landscape.

ui.png
- Heart, Coin icon, Score, Game Over, You Win.

sound_reference.png
- Tên file âm thanh gợi ý.
- Đây KHÔNG phải file âm thanh thật.

level_preview.png
- Hình xem trước một màn chơi.

LƯU Ý:
Các file trên được cắt từ một ảnh tổng hợp nên vẫn có phần nền/nhãn.
Để đưa trực tiếp vào C++/SFML, nên tạo sprite PNG riêng hoặc sprite sheet có
kích thước frame cố định ở bước tiếp theo.
